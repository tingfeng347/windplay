# New games — Experience

## Direction contract
THESIS: 打开即进入可玩世界。用户已明确要求内容与玩法完整；参考类型已固定为纪念碑谷式空间解谜与 ASCII 地牢。
OWN-WORLD: 折光之径以浅青天空、象牙石、珊瑚色旅人构成等距建筑；余烬地牢以炭黑底、纸白文字、琥珀火光与苔绿色地图构成真正的字符世界。每个游戏使用运行时几何/字符渲染，不依赖装饰性图像。
STORY: 看懂目标、尝试第一步、逐渐掌握规则，随关卡或地牢楼层获得新挑战；每次失败或通关都有明确后续动作。
FIRST VIEWPORT: 解谜建筑占屏幕主体，左侧展示章节、故事、目标，底部旋转控制，右侧十章索引。地牢地图占约三分之二视口，侧栏显示生命、物品与探索日志，底部提供方向和行动按钮。手机改为垂直布局，操作始终可达。
FORM: 用户指定游戏类型，直接继承类型的空间与字符表达；启动台延伸既有缩略图系统。关键动作为真实视角旋转和逐回合迷雾揭示。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
