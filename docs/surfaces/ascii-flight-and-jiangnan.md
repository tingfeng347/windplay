# 字间飞行与烟雨江南

## Scope

Experience：两个独立的浏览器作品，延续 WindPlay 启动台的入口和预览样式。用户已指定飞行显示方式和操纵参数，并指定园林的写实方向、非对称布局、室内结构、陈设、天气、日夜和视角；其自由发挥授权覆盖构图、植物和技术实现。

## Direction contract

THESIS：作品先于界面。飞行通过字符组成可操纵的空间；园林通过可进入的木构建筑展示居住尺度，不依赖静态背景画。

OWN-WORLD：飞行固定等宽字格，纯黑天空、青灰楼房、绿叶、金色航门；园林取粉墙、湿石、黛瓦、旧木与草木本色，轻量控制围绕画面。

STORY：飞行选择航线、保持姿态、穿门、失误重飞；园林环绕、进入、移步到各功能空间、切换时辰、揭顶看木构。

FIRST VIEWPORT：飞行画面占满操作区，左上仪表、右上姿态、中央起飞说明，底部航线状态；园林默认略高于庭院的环绕视角，左下室内去处，底部日夜滑杆和揭顶操作。

FORM：用户指定的实时体验世界覆盖概念分配；种子 47d87499 的第三候选取“观察到入内”的交互路径；界面材料与字符显示、真实园林要求冲突时，以用户要求为准。代码直接建构空间，禁止以效果图替代可漫游建筑。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Validation

飞行检查角速率、限幅、速度、线性协调转弯、扫掠碰撞、航门穿越和路线位置。园林检查生成参数、主空间可达性、阻挡、水岸和日夜连续性。构建验证 demo 新鲜度、内联依赖和脚本语法。

画面验收以实际运行的桌面、触屏布局与室内视角为依据；README 保持简短，详细设计和限制留在各作品 docs/。
