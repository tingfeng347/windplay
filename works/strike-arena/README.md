# 临界行动 / Strike Arena

原创第一人称三维战术射击演练。走进工业园，在四分钟内完成十五次击杀：利用集装箱、木箱、装卸平台和仓库掩护，使用卡宾枪、手枪和手雷应对会巡逻、绕行并开火的敌人。

[在线游玩](https://tingfeng347.github.io/windplay/works/strike-arena/demo/index.html) · [离线成品](demo/index.html)

## 运行

- 成品无需安装：直接打开或下载 `demo/index.html`，点击「开始行动」。程序、样式、像素材质和音效全部内嵌，离线运行，不使用 CDN、外部图片或商业游戏素材。
- 开发前提：Node.js 22+。该作品没有第三方依赖；也可以从仓库根目录 `npm ci` 安装所有工作区。
- 开发：`npm run dev --workspace @windplay/strike-arena`，默认 `http://localhost:5178`，可用 `PORT` 指定其他端口。源码变更会重新构建，刷新浏览器查看。
- 构建：`npm run build --workspace @windplay/strike-arena`。
- 测试：`npm test --workspace @windplay/strike-arena`。
- 输出：`dist/index.html` 和跟踪于 Git 的 `demo/index.html`。编辑 `src/` 后构建同步，不能手动修改生成的成品。

## 战场与战斗

64 × 56 的原创工业园，包括波纹金属仓库、集装箱、筒仓、管道桥、办公室、门窗、灯具、排水网格、木箱、油桶、沙袋和运输卡车。装卸平台有真实碰撞与可走的楼梯。定向光照、投影阴影、距离雾和程序生成的沥青/混凝土/木材/金属材质形成一致的场景。

敌人是原创比例人形网格：头盔、面罩、护甲背心、分节手臂与腿部、靴子和双手持枪。敌人会巡逻，发现玩家后追踪并绕过障碍；视线感知与枪口射击分别检查遮挡，不能隔着木箱或墙体造成伤害。近距被低掩体挡住时仍会尝试换位。

- **AR-9 卡宾枪**：30 发弹匣，全自动；有扩散与持续射击反冲，瞄准降低扩散。
- **P-12 手枪**：12 发弹匣，半自动。独立弹药与换弹时间。
- **手雷**：每次出场 2 枚，有飞行、碰撞、引信与衰减范围伤害，墙体可以挡住爆炸。
- 头部命中造成更高伤害，卡宾枪头部命中可以一枪击倒。护甲吸收部分伤害。
- 三种难度：新兵、老兵和不会还击的靶场。击倒后 3 秒复活，恢复武器、护甲与手雷；击杀数和回合计时保留。
- 四分钟内完成 15 次击杀获得胜利。结果显示击杀、阵亡、头部命中、命中率与积分；最高分和设置保存在当前浏览器。
- 原创双手持械、换弹姿态、枪口焰、抛壳、弹道、命中标记、击杀反馈和爆炸火星。Web Audio 合成枪声、脚步与机械操作音，可在暂停菜单关闭。

## 操作

| 动作 | 桌面 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 观察 | 鼠标 |
| 射击 / 瞄准 | 鼠标左键 / 右键 |
| 冲刺 / 跳跃 | Shift / 空格 |
| 换弹 | R |
| 卡宾枪 / 手枪 | 1 / 2；或滚轮与底部按钮 |
| 投掷手雷 | G / 底部手雷按钮 |
| 战绩 / 手册 / 暂停 | Tab / H / Esc |

手机使用方向按钮移动，拖动画面观察，点击「瞄准」切换瞄准状态，按「开火」「换弹」「跳跃」执行操作。底部切枪和手雷按钮可以直接点选。浏览器拒绝鼠标锁定时，桌面也显示这些屏幕按钮：**拖动画面只负责观察，开火与瞄准使用屏幕按钮**，不会因拖动观察消耗弹药。

建议第一次先选择「靶场」，熟悉移动、观察、换弹与瞄准，再尝试新兵。站稳、点射与头部命中能节省弹药；进入掩体后再换弹。

## 浏览器与范围

需要现代 Chrome、Edge、Firefox 或 Safari，启用 WebGL 1.0 与硬件加速。推荐桌面键鼠；支持手机触屏布局与较低渲染分辨率的「流畅」选项。没有 WebGL 时显示明确错误界面；图形上下文丢失时请刷新页面。声音只在开始行动等交互后启用。

这是原创单人演练，参考经典战术射击的操作节奏；不是 CF 或任何商业游戏的移植，没有联网对战、反作弊、商业枪械/人物资产或完整军事模拟。地图、角色和武器使用程序几何构建，属于小型浏览器游戏的实时图形规模；没有写实摄影资产、骨骼动画或动态全局光照。导航使用地面路径，敌人不会登上平台。最佳战绩可能被浏览器隐私模式或存储清理移除。

## 源码与检查

- `src/core.js`：确定性地图与敌人、碰撞、射线/头部命中、枪械/弹药/护甲、视线感知和地面导航、手雷、回合与战绩验证，可在 Node.js 直接运行。
- `src/renderer.js`：原生 WebGL、程序材质、工业场景、比例人形与第一人称双手、照明、雾和战斗特效。
- `src/game.js`：浏览器输入、锁定与拖动退化、触屏、HUD、菜单、音效、本地战绩和设置。
- `assets/preview.svg`：基于游戏模型重新投影的工业园与第一人称持枪 SVG 封面，统一建筑透视及枪械、双手的遮挡关系；[封面维护说明](../../docs/GAME_COVERS.md)。
- `tests/`：地图与敌人生成、射线/遮挡、真实开火和弹药、换弹互斥、反冲对齐、平台/楼梯/边界、导航绕行、枪口遮挡、护甲/复活、手雷/回合、损坏战绩验证、渲染数值与独立成品同步。

`window.StrikeArena.game` 只读提供状态快照、运行状态、当前菜单和场景顶点数，便于检查实际运行；不提供调试修改按钮。
