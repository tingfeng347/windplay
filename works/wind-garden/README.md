# 听风花园 / Wind Garden

一座可以种植旋律的浏览器花园。每株植物是一枚音符：横向位置决定演奏时间，纵向位置决定音高，花的形状和颜色决定音色。风从左向右经过植物，循环奏响你种下的乐谱。画面由 Canvas 2D 绘制，声音由 Web Audio 实时合成；植物、预览插画与合成音色均为原创，不加载音频文件或网络素材。

[单文件成品](demo/index.html)

## 开始

- 无需安装：下载并用浏览器打开 `demo/index.html`，点击「让风吹起来」开始听风。
- 本地开发需要 Node.js 22+。本作品没有第三方依赖；仓库根目录的 `npm ci` 安装全部工作区依赖。
- 开发：在仓库根目录执行 `npm run dev --workspace @windplay/wind-garden`，打开 `http://localhost:5179`。修改 `src/` 后自动重新构建，刷新页面查看。
- 构建：`npm run build --workspace @windplay/wind-garden`。
- 验证：`npm test --workspace @windplay/wind-garden`。
- 输出：`dist/index.html` 与跟踪在 Git 中的 `demo/index.html`，均内联全部脚本与样式，可独立离线打开。请修改 `src/`，再通过构建更新成品。

## 花园如何发声

花园共有 16 步、9 行音高，最多种植 48 株植物。每一步占半拍，一圈共八拍；速度可在 48～144 BPM 之间调整。默认 88 BPM，打开时已有一段由 20 株植物组成的示例旋律。

从上到下的音高为 E5、C5、A4、G4、E4、C4、A3、G3、E3，也就是由哆、咪、嗦、啦构成的九行音阶。越靠上，声音越高；同一列的植物一起发声。

| 植物 | 颜色 | 声音 |
| --- | --- | --- |
| 风铃 | 浅黄 | 清亮、逐渐消散的钟声 |
| 芦笛 | 珊瑚 | 柔和、带呼吸感的笛声 |
| 拨弦花 | 蓝色 | 短促、温暖的拨弦声 |

同一格可以放置不同音色，组成和弦。同一格、同一音色只保留一株；把植物拖到已有相同音色的格子时，会保留它原来的位置。

## 操作

先选择音色，再点击花园的空格种植。点击已有植物选中它，拖动可以改变节拍与音高；也可以在「花园里的植物」下拉列表中选择，用「拍点」和「音高」菜单精确调整，再使用「移除这株」按钮移除。编辑、种植、删除、导入、清空和载入示例都可以通过「撤销」返回之前的花园。

点击或按 Tab 聚焦花园后，可以使用键盘：

| 按键 | 操作 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| 方向键 | 移动已选植物；未选中植物时移动种植光标 |
| Enter | 在光标位置种植；已选植物时试听 |
| Delete / Backspace | 删除已选植物 |
| Esc | 取消选择 |
| Ctrl / Cmd + Z | 撤销最近的编辑；输入控件保留自己的撤销行为 |

手机和平板可以直接点击种植、拖动植物；花朵靠得很近时，可用植物选择列表、拍点和音高菜单精确编辑。调整速度会改变风经过花园的快慢，音量滑块控制整个花园的声音。

页面初始保持静音，只有主动播放或试听后才建立音频。切换标签页或将浏览器放到后台时会停止演奏，返回后点击「让风吹起来」继续。音频被系统中断时会明确暂停；不支持声音的环境仍可观察风经过植物。

## 保存与交换

「保存花园」将当前植物、速度与音量写入本机浏览器，下次打开会优先恢复已保存的花园。保存是手动操作，编辑不会自动覆盖旧存档；页面中的成功或失败提示会说明结果。

「导出」下载可读的 JSON 文件。「导入」选择 JSON 花园文件，验证成功后替换当前乐谱，仍可撤销；损坏文件、未知音色、越界位置、重复植物和超过 48 株的存档会被拒绝。导出文件适合备份，也可以发给朋友导入。

浏览器存储按访问地址分别保存，直接打开文件和通过本地服务访问可能使用不同的存储空间。重要旋律请保留导出的 JSON 文件；浏览器禁用本地存储时仍可编辑、播放和导入导出。

## 浏览器要求与边界

需要支持 Canvas 2D、Pointer Events 和 Web Audio 的现代 Chrome、Edge、Firefox 或 Safari。首次发声需要用户点击或键盘操作；不支持音频的环境会给出提示。触屏已适配，也可用键盘完成花园编辑。

这是一个固定音阶、16 步循环的音乐玩具，导出的是可继续编辑的花园 JSON，不是音频录音。植物的位置就是乐谱，存档不包含播放进度。

## 源码与验证

| 路径 | 内容 |
| --- | --- |
| `src/core.js` | 音阶、不可变植物编辑、节拍事件、坐标映射与严格存档验证 |
| `src/audio.js` | 三种原创合成音色与 Web Audio 演奏时钟 |
| `src/render.js` | 清晨花园、植物、风带、光标与选择状态的 Canvas 绘制 |
| `src/app.js` | 播放、指针与键盘编辑、撤销、保存、导入导出和后台停音 |
| `src/index.html`、`src/styles.css` | 页面控件、布局与响应式样式 |
| `assets/preview.svg` | 原创花园插画预览 |
| `tests/` | 编辑状态、拖动取消、容量与冲突、序列和音高、音频时钟与中断、存档安全、成品新鲜度及离线依赖检查 |

测试在 Node.js 中加载独立核心模块，检查操作前后的状态与乐谱往返；用模拟音频时钟检查预排节拍、回环、调速、静音、中断与长时间阻塞；用轻量 DOM 替身回归拖动取消与导入失败。成品测试确认最新源码已完整内联、所有脚本能解析，且没有远程资源或未替换的构建标记。
