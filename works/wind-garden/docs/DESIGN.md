# 听风花园 · 设计约定

## 方向

音乐是一座侧面可见的花园：横向是十六个半拍，纵向是九个音高。花朵的位置直接组成旋律，风从左到右经过时触发声音。开场给用户一段可听、可改的旋律，页面主体始终是活的花园，而不是介绍图或控件面板。

## Token

| 名称 | 色值 | 用处 |
| --- | --- | --- |
| 雾蓝 | `#E5F1ED` | 页面和清晨天空 |
| 深叶 | `#194C45` | 正文、主操作、茎叶 |
| 草地 | `#739C77` | 地景、辅助标记 |
| 风铃黄 | `#F2CE71` | 风铃的五瓣花与种子 |
| 芦笛珊瑚 | `#D97A70` | 芦笛的穗状花 |
| 拨弦蓝 | `#719FC2` | 拨弦的圆形花球 |

辅助白色 `#FAFCF6` 用在轻薄的工具条；文本避免放在透明的花色上。焦点使用深叶色三像素轮廓。主按钮叶绿色实底，次按钮透明，危险动作只在动作发生时给出撤销。

标题用本地 `Songti SC / STSong / Noto Serif CJK SC / serif`，像植物观察册中的题字；操作文字使用本地 `PingFang SC / Microsoft YaHei / sans-serif`。不下载字体，离线使用保持完整。字号：桌面标题 46px、移动标题 34px、正文与操作 14px、辅助说明 12px。数字节奏用同一无衬线字体，保持界面安静。

## 布局

所有正文左对齐。顶部是作品名与一句操作引导，右侧是启动风的明确按钮。桌面花园高 520px，宽度随页面变化，占首屏超过一半；手机花园高 410px，保留九个音高和十六个半拍。下方是一条种子盘、速度和音量组成的工具带，存档动作另起一行。

```text
返回游乐场                                  声音状态
听风花园                         [让风吹起来]
种一朵花，风就多唱一个音。
┌──────────────────────────────────────────┐
│ 音高  花园：花朵 / 茎叶 / 草地 / 经过的风 │
│       花朵越高，音越高；风向 →            │
│       1  2  3  4 … 16 个半拍              │
└──────────────────────────────────────────┘
[风铃] [芦笛] [拨弦]      速度 ─●─  音量 ─●─
选中植物：音高 / 位置 / 删除      撤销、保存
```

## 对照需求后的取舍

初稿中的边栏和卡片会使音乐场景退化成设置页，最终改为完整横向花园与单层工具带。色彩来自清晨植物与三种音色，不使用深色霓虹、仪表盘卡片或随机装饰。风的移动、花瓣张合和茎叶弯曲都由播放节奏与真实音符状态驱动，减少动态偏好时停用闲置摇摆与粒子，保留静态节拍指示。

## 交互约定

- 空地点击种植；按住花头拖动同时改变音高与时机。
- 花的三个形状对应三个真实合成音色，不仅靠颜色区分。
- 光标选中花头后，方向键移动半拍或音阶，Delete 删除；空地光标以 Enter 种植。
- 删除、清空、载入示例和导入均可撤销。清空需要明确确认，导入要先校验。
- 只有用户启动播放或试听后才创建 Web Audio。后台自动暂停并要求再次主动播放。
- 本地保存失败会说明如何用 JSON 导出保留作品；不假装已保存。
