# 游戏说明

## 操作与规则

- 左右方向键 / A、D：移动；Space / Z / W / ↑：跳跃，长按更高，水下重复按游泳。
- Shift：加速；X：加速并发射火球；↓ / S：站在管道上进入金币房，在出口管道上按下返回。
- P / Escape：暂停；手机使用画面下方的多点触控手柄。横屏更适合游玩。
- 顶问号砖得到金币、蘑菇、火焰花或星星；大形态可顶碎砖，踩龟后可踢龟壳；100 金币奖励生命。
- 普通关到达旗杆过关；城堡越过库巴触及斧头，火球击中 5 次也能击败库巴；8-4 救回公主。
- 4-4、7-4 按屏幕指示走高路、低路；走错会返回该段路口。8-4 中间有水下区。
- 分数、当前关卡、道具和通关记录自动存入 localStorage。存档恢复从当前关起点出发。文件协议存档是否持久由浏览器决定，拒绝存储时仍可游玩。

支持具有 Canvas 2D、Pointer Events、requestAnimationFrame 的现代 Chrome、Edge、Firefox、Safari。音效通过用户开启后的 Web Audio 合成，全屏随浏览器支持情况启用。

## 还原范围

32 个编号、场景类型和各世界递进机制依据初代参考，第一关保留经典的管道、深坑和台阶节奏，8-1 保留长关设计。各关地形为独立手写数据，不是随机生成。像素角色与场景由代码绘制，音效为合成。

这是重建版本，并非 ROM 模拟器或逐像素、逐帧完全复刻。物理参数、敌人时序、关卡坐标有差异；城堡迷宫为可见的上下路径判定，管道为金币房，未实现原版全部隐藏砖、传送世界、循环房间和原曲。地图参考：[Ian Albert 的初代完整地图](https://ian-albert.com/games/super_mario_bros_maps/)。

## 技术与构建

原生 Canvas 2D，无运行时依赖，不加载 ROM 或外部素材。构建生成 `dist/index.html` 和受 Git 跟踪的 `demo/index.html`。测试覆盖关卡、碰撞、状态、存档与成品新鲜度。
