# 方块旷野 / Voxel Frontier

一款独立、离线可玩的三维方块建造与生存游戏。原生 WebGL 绘制有像素纹理的地形、森林、矿脉、湖泊与方块动物；相同种子生成相同的世界。画面、程序与规则均为原创实现，受到经典方块沙盒游戏启发。

[在线游玩](https://tingfeng347.github.io/windplay/works/voxel-frontier/demo/index.html) · [单文件成品](demo/index.html)

## 开始

- 无需安装：下载或直接双击 `demo/index.html`，在浏览器进入创造或生存模式。
- 本地开发需要 Node.js 22+；本作品没有第三方依赖。从仓库根目录执行 `npm ci` 安装各工作区，或直接使用下面的构建命令。
- 开发：根目录运行 `npm run dev --workspace @windplay/voxel-frontier`，默认地址 `http://localhost:5175`。修改 `src/` 后自动重新构建，刷新浏览器查看。
- 构建：`npm run build --workspace @windplay/voxel-frontier`。
- 验证：`npm test --workspace @windplay/voxel-frontier`。
- 输出：`dist/index.html` 与跟踪在 Git 中的 `demo/index.html`。两者都内联脚本、样式与程序生成纹理，不使用 CDN 或网络素材。只编辑 `src/`，通过构建同步成品。

## 可以玩什么

- 80 × 80 × 48 的随机体素世界，25 个独立网格区块；包含草地、沙岸、树木、野花、煤矿、铁矿和不可破坏的基岩。
- 第一人称观察，碰撞、重力、跳跃、冲刺、涉水；创造模式可以飞行。
- 最长 6 格的射线采矿与放置，持续挖掘进度、工具速度和耐久；放置不会把玩家封进方块。
- 九格快捷栏、背包和 11 种合成配方。生存流程从原木、木板和木棍开始，制作镐采集石头、煤矿与铁矿，再制作更好的工具、石剑、玻璃和发光灯石。
- 昼夜循环、生命与饱食度、食物、坠落伤害和自动回血；夜间暗影会追逐并攻击，灯石附近会抑制近距离攻击。白天动物可提供食物，暗影可提供煤。
- 同一世界可在创造与生存模式切换，切换模式会重置背包：生存提供初始物资，创造提供无限方块。
- 浏览器存档、继续游戏、手动保存、30 秒自动保存、JSON 导入/导出与新种子。已有存档时，新建世界会等你第一次主动保存后才覆盖旧存档。
- 暂停、玩法手册、可开启的原创合成音效、地图和触屏移动/观察/挖掘/放置按钮。

## 控制

| 操作 | 键位 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 观察 | 鼠标；触屏拖动画面 |
| 跳跃 / 冲刺 | 空格 / Shift |
| 挖掘、砍树、攻击 | 按住鼠标左键 |
| 放置 / 食用已选食物 | 鼠标右键 |
| 选择快捷栏 | 1–9 / 鼠标滚轮 / 点击快捷栏 |
| 背包与合成 | E |
| 吃背包中的食物 | R |
| 创造飞行开关 | F |
| 飞行上升 / 下降 | 空格 / C |
| 玩法手册 / 暂停 | H / Esc |

手机使用左侧方向键移动、右侧按钮跳跃和建造，拖动画面观察。部分浏览器拒绝鼠标锁定时，会显示屏幕操作按钮，可以拖动观察。

生存模式开局自带 8 原木、32 泥土和 8 浆果。先按 E 制作木板 → 木棍 → 木镐，再把木镐装入当前快捷栏；使用镐挖石矿才能获得资源。放置石头可作为墙体，再制作灯石照亮庇护所。死亡后回到安全出生点，背包和世界保留。

## 浏览器要求与边界

支持启用 WebGL 1.0 的现代 Chrome、Edge、Firefox、Safari。不开启硬件加速或 WebGL 时，会显示明确的恢复提示。WebGL 上下文丢失时请保存或导出存档，再刷新页面。触屏已经适配，但桌面键鼠是推荐的游玩方式。

这是一个完整可玩的原创小型沙盒，不是原版游戏移植。世界边界有限，不含联机、红石、下界、复杂敌人 AI 或原版素材。动物会简单游走，暗影追逐玩家；复杂的立体路径不会自动寻路。灯石纹理会发光，但没有体积光与逐方块光照。存档包含方块编辑、背包、玩家状态与时间；动物位置在重新进入后生成。浏览器存储可能被隐私模式或系统清理，请使用导出存档保留重要作品。

## 源码与验证

- `src/core.js`：确定性生成、体素世界、碰撞与射线、采矿放置、工具、合成、生存、严格存档验证，可在 Node.js 直接测试。
- `src/renderer.js`：原生 WebGL、程序生成像素纹理、区块网格、昼夜雾色、方块角色与目标边框。
- `src/game.js`：输入、菜单、主循环、动物/暗影、音效、触屏操作、存档与地图。
- `assets/preview.svg`：原创等距方块景观预览。
- `tests/`：确定性地形、碰撞、射线、创造/生存放置、真实采集与合成流程、耐久、伤害和饥饿、存档往返及无效存档、安全复活、单文件成品新鲜度。

`window.VoxelFrontier.game` 只读提供当前游戏的状态快照、菜单、运行状态、网格和角色数量，方便检查运行情况；不提供改变游戏的调试按钮。
