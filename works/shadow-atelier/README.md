# 影子工坊 · Shadow Atelier

转动看似凌乱的立体雕塑，让一盏灯投出的影子拼成猫、飞鸟、钥匙、灯塔、茶壶与蝴蝶。六关全部可选，每关都有常驻的目标剪影、逐步提示和通关定格。通关记录保存在当前浏览器；存储不可用时仍可完成所有关卡。

## 运行

- 直接打开 `demo/index.html` 即可离线游玩，成品没有外部运行依赖。
- 开发和构建需要 Node.js 22 或更新版本，浏览器作品不需要安装依赖。
- 从仓库根运行 `npm run dev --workspace @windplay/shadow-atelier`，访问 `http://localhost:5180`。可用 `PORT` 更换端口。
- 在本目录运行 `npm run dev`、`npm run build` 或 `npm test`。
- 构建把 `src/index.html`、`styles.css`、`core.js`、`render.js`、`app.js` 内联为 `dist/index.html` 和受版本控制的 `demo/index.html`。请修改源码后重新构建，不要手改成品。

## 操作

- 鼠标或单指拖动展厅：横向调整左右，纵向调整俯仰。第一、二关固定侧倾，其余关卡可以调整三个方向。
- 拖动三个角度滑杆可精确调整；按 Tab 聚焦展厅后，方向键调整俯仰 / 左右，Q / E 调整侧倾。按住 Shift 使用一度微调。电脑也可按住 Shift 横向拖动调整侧倾。
- 影子吻合度达到 90%，松开并保持 0.6 秒即可定格。评分直接比较真实墙影与目标的像素并集，不比较角度距离。
- 「给我一点提示」先描述形状，再逐个给出方向角度。没有一键通关，仍需亲手调整雕塑。
- 「重新摆放」换一个明显不吻合的姿态。「上一束光」「下一束光」和选关菜单切换谜题。通关后可以「再拼一次」。

## 投影与实现

每个目标由原创几何剪影生成实体立方块 / 长方块，块在深度方向错开；关卡建立时对块的所有顶点施加解姿态的逆旋转。玩家控制三轴 Euler 旋转，单一方向光沿 -Z 投到固定墙平面。每块旋转后的八顶点在墙面的凸包是真实投影；这些多边形同时用于墙影显示和 112 × 112 二值 mask 的 union / IoU 评分。六个解姿态都达到 100% 吻合。

Canvas 2D 绘制的固定斜视镜头包含展墙、单灯、平台和经深度排序的立体面。立体块每帧按真实三维坐标旋转，不用角度切换预制图片。提示和目标来自同一关卡几何。

页面没有装饰性常驻动画；只在操作、大小变化和通关稳定计时期间绘制。隐藏页面取消帧循环和稳定计时。支持减少动态效果偏好、键盘控制、屏幕阅读器状态，以及 320px 宽布局。需要支持 Canvas 2D、Pointer Events、ES2022、CSS Grid 的现代浏览器；建议使用当前 Chrome、Edge、Firefox、Safari 或移动浏览器。

## 验证

`npm test` 覆盖旋转及逆变换、六关可解性与起始差异、一度容错、投影 union 与 IoU 归一、持续吻合判定、非法存档、构建源码一致性和脚本可解析性。`window.ShadowAtelier.inspect()` 返回只读状态快照，供浏览器验收查看当前关卡、角度、分数、定格状态与收藏记录。

画面采用软件绘制与画家排序；极少数交叉块的遮挡可能近似。该视觉近似不影响真实墙影或评分。字体使用系统字体，作品不加载在线字体、图片或音频。
