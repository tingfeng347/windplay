# 影子工坊的展厅设计

## 设计计划

作品的第一视觉是一件照在墙上的真实雕塑：暖灰展墙承接圆形灯光，烟紫立体块悬在木质平台上。控制区是展厅旁的一条工作台，与场景保持共同的墙面材质。目标图如同展品标签，始终可见。

用色：

| Token | 值 | 用途 |
| --- | --- | --- |
| plaster | #e0d8ca | 展厅底色 |
| ink | #3d3c42 | 标题与正文 |
| quiet | #59554f | 辅助说明，保持可读对比 |
| indigo | #565874 | 雕塑、吻合进度与操作重点 |
| light | #fbf4df | 单灯照亮的墙面 |
| wood | #b89572 | 木台材质 |

字体：中文标题采用系统宋体，展品的命名与材质相近；正文与控件采用 Avenir Next / 苹方 / 微软雅黑。标题 27–30px，控件与说明至少 12px，主要描述与提示 13px。角度与分数使用等宽数字，避免调整时的抖动。

桌面布局采用左侧大展厅、右侧 320px 工作台，左对齐的展品标题引出目标与控件。移动端展厅位于上方，工作台随屏幕宽度变为双列或单列；320px 宽时控制保持完整，按钮、滑杆和返回链接的操作区域至少 44px 高。

展厅容器独立承担布局尺寸：桌面由网格行和容器最小高度决定，手机由容器的 440px / 345px 固定高度决定。画布绝对定位覆盖容器，不参与网格的内容尺寸计算；其像素宽高仅用于 DPR 渲染，不能反过来改变页面高度。手机的吸顶仍由展厅容器负责。

```text
桌面： 标题 / 返回首页                     收藏数
       ┌─────────────────────┬────────────┐
       │     墙影    立体块   │ 关卡与目标  │
       │      单灯 / 木台     │ 吻合度      │
       │                     │ 旋转 / 提示 │
       └─────────────────────┴────────────┘
手机： 标题 / 收藏 / 返回
       墙影与雕塑
       关卡与常驻目标
       吻合度 / 三个旋转方向
       提示 / 重新摆放 / 换关
```

## 审视与取舍

墙和灯的暖色由作品主题决定；不把暖色扩展成通用营销页卡片。展厅是唯一强视觉，其余界面只保留必要的分隔、数字和角度控制。没有霓虹、表情符号、卡片栅格、无关的过场或自动旋转。定格反馈用文字与普通边框表达，不添加装饰性条带。

目标与当前影子的轮廓来自同一投影算法，玩家能相信画面和吻合度一致。比例固定，不能通过自动平移或缩放降低解谜难度。第一、二关少一个自由度，后四关逐步出现镂空与侧倾；所有关卡仍从一开始就能访问。

无常驻自动运动；600ms 的成功稳定时间回应玩家的操作。隐藏页面停止计时与绘制，屏幕阅读器仅获得关键阶段反馈。减少动态效果偏好保持静止的展厅表达。
