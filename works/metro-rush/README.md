# 城市疾跑 · Metro Rush

追着落日穿过三条城市轨道的原创 **WebGL 3D 跑酷**。有动态第三人称角色、列车与车顶坡道、车站与街区、跳跃和滑铲、金币、道具、挑战与换装。几何、角色、配色、音效与预览均原创，未使用商业跑酷游戏的角色、界面、音乐、商标或素材。

## 直接游玩

打开 [`demo/index.html`](demo/index.html) 即可，单文件自包含，无运行时依赖或 CDN，可离线游玩。需要支持 WebGL 的现代 Chrome、Edge、Firefox、Safari，并启用硬件加速。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 换道 | ← → / A D | 左右滑动 / 方向按钮 |
| 跳跃 | ↑ / W / 空格 | 上滑 / 点击场景 / ↑ 按钮 |
| 滑铲 | ↓ / S | 下滑 / ↓ 按钮 |
| 悬浮板 | B | 双击场景 / 悬浮板按钮 |
| 暂停 | Esc / P / 暂停按钮 | 暂停按钮 |

- 橙色路障需跳过；红色横梁需滑过。换道也能避开。
- 列车不能直接穿过；银色坡道可以带你跑上列车车顶。
- 每次旅程有两块悬浮板，一次启动持续 12 秒或抵挡一次碰撞。
- 圆形道具分别提供磁力吸币、强化弹跳、双倍积分和悬浮护盾。
- 速度由 14 米/秒逐渐升至 29 米/秒；生成区段保留可通行路线。
- 挑战完成增加 500 分，结算时每项奖励 20 金币；金币可解锁原创服装。
- 最高分、钱包、衣橱与设置保存在当前浏览器的 `localStorage`。关闭网页后当前跑程不保留。无存储权限时仍可游玩，但成绩仅在本次页面有效。
- 设置支持音效、动态反馈和高清 / 流畅画质。切换标签页或离开窗口自动暂停。

## 开发

从仓库根目录执行：

```sh
npm ci
npm run dev --workspace @windplay/metro-rush
npm run build --workspace @windplay/metro-rush
npm test --workspace @windplay/metro-rush
```

开发端口 `http://localhost:5177`，可通过 `PORT` 覆盖。源码变化会重新构建，刷新页面查看。

- `src/engine.js`：Node 可导入的确定性区段生成、角色运动、碰撞、道具、积分、挑战与存档规则。
- `src/renderer.js`：原创几何、WebGL 光照/雾效、相机、分区网格缓存和动态角色。
- `src/game.js`：键盘与触屏、倒数/暂停/结算流程、音效、服装与设置。
- `src/styles.css`：响应式游戏界面。
- `assets/preview.svg`：原版 1600 × 900 低多边形城市轨道封面，保留场景与角色，调整列车接缝并清除重复文字；[封面维护说明](../../docs/GAME_COVERS.md)。
- `scripts/build.mjs`：内联源码生成 `dist/index.html` 和受版本控制的 `demo/index.html`。
- `tests/`：确定性、通路、碰撞、坡道车顶、护盾、得分、流式清理、解锁与成品一致性测试。

`window.MetroEngine.game` 与 `window.MetroEngine.savedProfile` 提供只读状态快照，可用于浏览器验收。请编辑 `src/` 后重新构建，不要手动修改 demo 或 dist。

当前为完整单人无尽跑酷核心，没有多人排名、账号云存档、商业游戏的关卡内容或大型游戏引擎的后期效果。
