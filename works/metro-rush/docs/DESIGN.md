# 场景与系统

城市疾跑用日落时分的铁路城市建立自己的视觉：蓝灰轨道、暖色楼体、青绿信使与珊瑚色鞋帽。镜头从人物背后观察，看到更远的障碍；帽子、马尾、夹克图案和摆动肢体组成原创角色。静态城市用窗户、遮阳棚、树、长椅、街灯、钢梁、轨道与站棚建立尺度。天空为几何渐变与太阳，远景用雾衔接。

原生 WebGL，无外部图片、字体、音频、CDN 或第三方运行时。区段静态几何缓存在 GPU 缓冲区，走过后释放；金币和人物每帧动态绘制。低画质降低渲染像素量，高清最多使用 1.6 倍像素密度。

竖屏使用更强的镜头跟随与稍远的观察距离，直接跟随角色已经平滑的换道位置，避免快速跨道时滞后裁掉身体。投影测试验证 320 / 390 像素宽下，地面、跳跃和车顶状态的人物都保留屏幕边距；桌面保留较安静的横向镜头。

每区段为 48 米，种子与区段编号确定障碍及城市外观。区段生成保证任意纵向位置至多两道被障碍占据，保留换道路径。初始区段提供无障碍金币引导，随后引入路障，再扩展为横梁、列车、坡道和双列车通道。

运动在世界距离上推进，跳跃用重力弧线，换道用平滑收敛。碰撞按脚底高度与站立/滑铲身高判断；坡道连续抬高地面，满足高度条件后可在车顶跑动。悬浮板吸收撞击后提供短暂无敌，避免同一列车连续判定。

积分按每次前进的距离与当时倍率累计，双倍效果结束不会清除已获得的额外分数。任务先完成再计入积分，碰撞那一帧完成的挑战仍可结算。已经收取的道具和已通过的障碍保留标记，过期区段的标记一起清理。

控制器有开场、倒数、运行、暂停、模态和结算流程。说明/设置弹窗期间不能从键盘恢复后台运行；输入与引擎事件按对象游标消费一次，确保跳跃和悬浮板反馈及时。页面失焦自动暂停，WebGL 中断提供明确恢复提示。

存档验证版本、金额、分数、服装 ID 和设置类型。无权限或损坏数据会回到默认档案，不影响游玩。结算只执行一次，避免重复奖励。
