# 余烬地牢 · ASCII Delve

一款原创回合制 ASCII 地牢探索游戏。选择三种职业之一，穿越五层种子地图，找到每层铜钥匙，在第五层击败守火者并从阶梯带回火种。

[直接打开完整成品](demo/index.html)。零运行时依赖，无需服务器或网络。

## 玩法

- 五层地牢：苔石入口、遗忘水道、灰烬藏书室、无声陵寝、守火者的王座。
- 三种职业：守灯人（防御、药水），寻路者（攻击、视野），烛火学者（双倍震荡）。
- 方向键 / WASD 移动，撞击敌人攻击。移动、攻击、喝药、震荡与等待推进一个回合，敌人随后行动。
- H 喝药（恢复 20 生命），F 两格范围震荡，E 在阶梯下潜或在商人旁交易，空格 / `.` 等待。
- M 或地图按钮在跟随视野和已探索地图之间切换。
- `@` 旅人，`r/s/w` 普通敌人，`W` 首领，`k` 钥匙，`>` 阶梯，`!` 药水，`$` 金币，`/` 武器，`]` 护甲，`+` 一次性治疗泉眼，`&` 商人，`?` 碑文，`^` 陷阱。
- 每层钥匙在西南房间；阶梯在东南房间。下潜恢复 8 生命与震荡次数，钥匙需要重新寻找。
- 战斗赚取金币与经验；升级增加生命和攻击。探索可自动换装，在商人旁按 E 可购买药水或永久增加本局攻击/护甲。
- 守火者举刃蓄力时，后退可避开下一次攻击。失败后可以重玩相同种子，或选择新职业、新世界。
- 手机使用方向/行动按钮，也可在地图上滑动，每次滑动走一步。

只保存当前一局，每次行动自动保存在浏览器中，刷新后恢复地图、战斗与迷雾；开始新旅程会替换存档，并有明确提示与取消按钮。最佳楼层与通关次数单独保存。存储不可用或损坏时可继续游玩。

## 开发与浏览器要求

Node.js 22+；现代 Chrome、Edge、Firefox、Safari，需要 Canvas 2D、ResizeObserver。浏览器端没有外部依赖。

```bash
npm ci # 仓库根目录
npm run dev:delve
npm run build --workspace @windplay/ascii-delve
npm run test --workspace @windplay/ascii-delve
```

开发端口 `5182`，可用 `PORT` 覆盖。进入本目录亦可运行 `npm run dev` / `npm run build` / `npm test`。

`src/core.js` 是可在 Node 中测试的纯规则与地图生成器；`render.js` 负责字符渲染；`app.js` 负责输入、界面与持久化。构建内联为 `dist/index.html` 和 tracked `demo/index.html`，不要手改输出。

测试覆盖 300 个种子/楼层组合的确定性、可达性、无重叠、战斗成长、死亡、商店、楼层/首领胜利门槛、存档恢复和离线成品一致性。源码修改后先构建再测试，成品测试不会自行掩盖过期输出。
