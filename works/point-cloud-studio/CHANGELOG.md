# 变更记录

## 0.2.0

- 重新设计界面：大画面加右侧编号参数面板，画面内置 HUD 角标、实时视角读数和 2D / 3D 切换条。
- 亮色主题只改变界面，点云画面保持深色背景，避免白底下明暗反转、颜色发灰。
- 立体纵深默认值由 0.38 调整为 0.10。
- 支持把照片直接拖到画面上载入；复选框改为开关，滑块显示已填充进度。

## 0.1.0

- 移除独立 HTML 画布的边框、焦点轮廓和阴影，保留键盘交互。
- 将界面结构、样式、编辑器逻辑、采样和三维模块拆为独立源码。
- 加入可重复构建、开发文件监听、依赖锁定和回归检查。
- 附带完整彩色演示照片，以及 HTML、SVG、PNG 成品。
- 保留原图 RGB、默认鼠标扰动、三维旋转、已修正的上下拖动方向、双侧参数面板和亮暗主题。
