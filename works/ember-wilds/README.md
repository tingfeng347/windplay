# 余烬荒野 · Ember Wilds

原创纸墨荒野生存游戏。受生存沙盒的昼夜、饥饿与制作循环启发，以独立绘制的 Canvas 场景和原创角色呈现一片可探索的森林。作品没有使用商业游戏的素材、角色、商标界面或游戏源码。

## 游玩

直接打开 [`demo/index.html`](demo/index.html)，无需安装、网络或服务器。现代 Chrome、Edge、Firefox、Safari 均可，需支持 Canvas 2D 和 JavaScript。电脑与手机横竖屏均支持。

- **WASD / 方向键**移动，**Shift**奔跑；点击地面走过去，点击资源走近并采集。
- **E** 与最近的资源或建筑交互，按住可连续砍树 / 采石；**空格**攻击附近生物。
- **1 / 2 / 3** 食用浆果 / 熟食 / 生肉；也可点击背包中的食物。生肉会降低健康和精神。
- **C**切换制作栏，**M**切换地图，**Q**快捷制作火把，**Esc**暂停。
- 手机使用方向按钮、交互按钮、攻击按钮和制作栏。
- 页面每 15 秒自动保存，也可在暂停菜单手动保存。重新打开可继续。存档保存在当前浏览器的 `localStorage`，私密模式或禁用存储时无法持久保存。

## 第一个夜晚

1. 捡起树枝和燧石：3 树枝 + 2 燧石制作斧头。
2. 砍树取得木材：3 树枝 + 3 燧石制作镐子，采岩石取得石块。
3. 收集干草：4 木材 + 2 石块 + 3 干草制作营火，自动放在身旁。
4. 靠近营火按 E，消耗 1 木材添柴；雨中火会燃烧得更快。
5. 靠近燃烧的营火，点击烹饪，把 1 浆果或生肉变成 1 熟食。
6. 白昼 120 秒、黄昏 30 秒、黑夜 30 秒。没有营火或火把，黑暗会在 2 秒后伤害健康。

长矛用于战斗，木甲减伤，陷阱捕兔，庇护所可休息恢复精神。浆果两天后再长，干草与地面小资源三天后再长。地图的浅点是角色、橙点是营火。探索、制作和天气都会被保存；死亡后可以重新开始同一颗世界种子。

## 开发

从仓库根目录执行：

```sh
npm ci
npm run dev --workspace @windplay/ember-wilds
npm run build --workspace @windplay/ember-wilds
npm test --workspace @windplay/ember-wilds
```

开发地址：`http://localhost:5176`，设置 `PORT` 可覆盖。源文件变化后自动重新构建，刷新页面查看。

- `src/engine.js`：可在 Node 中导入的确定性状态引擎，资源、制作、战斗、昼夜、存档验证。
- `src/render.js`：原创 Canvas 场景、小地图和光照。
- `src/game.js`：输入、响应式界面、音效、自动存档与暂停。
- `assets/preview.svg`：原创 16:9 预览图。
- `scripts/build.mjs`：内联 CSS / JS，输出 `dist/index.html` 与受版本控制的 `demo/index.html`。
- `tests/`：确定性、交互、制作、黑暗、战斗、食物、陷阱、存档与成品一致性测试。

测试不依赖第三方库。`window.EmberWilds.game` 提供状态快照，供浏览器检查；修改快照不会影响正在运行的游戏。不要手动编辑生成的 demo / dist。

这是一个可玩、完整闭环的轻量作品，不是商业生存游戏的完整复刻：当前为单人、一个季节、有限制作配方，没有联机或地下世界。
