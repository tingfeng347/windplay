# 实现与视觉

森林是一张略带透视的纸墨地图。地面为苔灰 `#6d7350`，墨线 `#272d22`，纸色 `#d4c398`，树冠 `#3e4f37`，火光 `#d6974e`。场景的记忆点是有线描树冠、旅行者与小营火的连续荒野，界面采用安静的纸墨工具栏；不使用商业游戏素材或外部字体资源。

状态引擎不依赖 DOM，固定种子和相同输入产生相同结果。昼夜为 180 秒循环，天气、资源再生、敌人、陷阱和生命状态均由一次 `tick` 更新。单帧最多推进 0.12 秒，切页会自动暂停，避免离开网页后突然死亡。

存档带版本号，加载时验证必需字段、数值范围、实体类型和消息数组。恢复后清除正在行走的目标与休息状态，避免误操作。过大的数据或损坏数据会被忽略，允许重新开局。

渲染使用世界坐标排序与屏幕投影。营火 / 火把从夜色遮罩中消去光照区。游戏文字使用系统宋体，所有资源图形、动物、角色和建筑均由几何路径实时绘制；单文件成品无需联网。
