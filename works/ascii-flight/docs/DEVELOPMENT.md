# 字间飞行：操纵与开发

## 运行

开发需要 Node.js 22+，在仓库根目录运行 `npm ci`。作品使用原生 JavaScript、Canvas 2D 和 esbuild。`npm run dev --workspace @windplay/ascii-flight` 启动热构建预览；`PORT=4174` 可指定端口。

`npm run build --workspace @windplay/ascii-flight` 从 src 构建 dist/index.html 与 tracked demo/index.html。demo 内联所有代码、样式，可用 file:// 离线打开。支持现代 Chrome、Edge、Firefox、Safari，需要 Canvas 2D，不需要 WebGL。

## 操纵

- W 增加俯仰、抬高机头，S 降低俯仰、压低机头，变化速率为 60°/s。
- A 左滚转，D 右滚转，变化速率为 60°/s。
- 俯仰与滚转都限于 ±45°；松杆保持角度，不自动回中。
- 偏航角速度 = 滚转角 / 45° × 90°/s，进行线性协调转弯。
- Z 加速，X 减速，变化速率为 10 m/s²；速度限制为 10–50 m/s。
- P / Esc 暂停或继续，R 重飞。
- 触屏按住底部操纵键；失焦、隐藏页面、取消触摸时释放所有输入并暂停。

## 内容

四条航线：城市穿针（12 门）、滨河回环（18 门）、公园低空（16 门）、工业远征（14 门），另有自由飞行。穿过所有金色航门即可完成航线；楼房、树冠、地面发生碰撞后可重飞。航线最快用时保存在浏览器本地，存储不可用时仍可完整游玩。新城市使用独立的纪录键，不将旧航线用时算作新航线成绩。

城市覆盖约 1.7 × 2.2 公里的空域，街道间距随街区变化。商业区含高楼退台、屋顶设备和两座可从下方穿过的连廊；西侧为低层住宅、钟楼与公园，东侧曲折河流由四座桥连接，北侧仓库区有烟囱与吊架。树木由树干和多层树冠组成，建筑部件与桥面均参与实际碰撞；自由飞行可自行选择绕过、穿过或越过障碍。测试检查航门连接路径，并使用实际角速率控制在 15 m/s 下飞完四条航线；测试控制器不是游戏内自动驾驶功能。

## 显示

世界使用 CPU 射线和深度缓冲判断可见表面，最终只通过固定等宽网格的 ASCII 字符显示。canvas 只调用 2D 填字，没有 Three.js 或 WebGL。建筑以 # / H / = / - 表示墙面、窗格和屋面，树冠用 * / + / &，道路用 . 和中心线 =，人行道用冒号，河流用蓝色 ~ / -，草地用逗号，天空没有字符且纯黑。航门用 O / +，并参与深度遮挡。

渲染先将附近建筑的八个角投影到字符列，按保守边界筛选每列可能命中的物体，再执行同样的射线与深度判断。跨过镜头平面的物体保留在所有列，避免近景裁掉建筑；增加细节不依赖降低字格精度。

## 验证

`npm run test --workspace @windplay/ascii-flight` 检查角度、角速率、速度限制、线性协调转弯、运动距离、扫掠碰撞、航门方向、确定性城市、航门位置、离线 demo 与源码一致性。

## 启动台预览

`demo/index.html?preview=1` 隐藏操作界面，只从同一份场景源码绘制初始画面，不启动持续动画或模拟；页面缩放时重新绘制。可附加 `view=river`、`view=park`、`view=industrial` 查看对应区域的固定机位，仅在 preview 模式生效，不改变正常飞行出生点。首页缩略图通过浏览器截取该模式的真实画面并保存到 assets/screenshots/new-games，不嵌入活动场景。此模式不能替代正常页面的交互验收。
