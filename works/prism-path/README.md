# 折光之径 · Prism Path

纪念碑谷式视错觉玩法启发的原创等距空间解谜。转动世界，让原本不相邻的石台在投影中连接，带旅人收齐星光、穿过拱门。没有使用原作的角色、关卡或素材。

[直接打开完整成品](demo/index.html)。零运行时依赖，无需网络或服务器。

## 内容与操作

十章：初见、回廊、双生塔、潮汐机关、星盘、沉默的庭院、错位长阶、月之门、无尽之环、归光。

- 点击石台移动；同一段连通路径会自动逐格行走，也可使用「可走路径」按钮或数字 1–9。
- Q / E 或左右按钮旋转视角。金色桥头只在特定视角相接，连接遵守真实等距投影。
- 收齐本关所有星光，再进入拱门。第四章开始出现机关，站上后空格切换门。
- 第五章开始只能在带圆环的星盘上转动世界。
- Z 撤回，R 重走；指引给出当前状态的最短解下一步。
- 十章可自由选择；通关步数与星级自动存档。通关得一星，步数不超过最短解的 135% 加一星，未使用指引再加一星。
- 触屏可点石台与全部控制按钮。系统减少动态效果时取消旋转和步行动画。

当前关卡重新打开时从起点开始；已完成章节、最高星级、最佳步数保留。存储不可用时提示并继续游玩。

## 开发

需要 Node.js 22+。现代 Chrome、Edge、Firefox、Safari，支持 Canvas 2D、ResizeObserver 和本地存储（存储可降级）。

```bash
npm ci # 仓库根目录
npm run dev:prism
npm run build --workspace @windplay/prism-path
npm run test --workspace @windplay/prism-path
```

开发默认端口 `5181`，可用 `PORT` 覆盖。独立进入本目录也可以 `npm run dev` / `npm run build` / `npm test`。

源文件在 `src/`；构建内联为 `dist/index.html` 与 tracked `demo/index.html`，不要直接编辑成品。测试验证十章可解、桥梁投影、机关、旋转限制、进度恢复与成品一致性。运行测试前若修改了源码，先构建；成品测试不会自行覆盖 stale demo。
