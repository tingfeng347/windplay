# Display lettering

Subset of ZCOOL XiaoWei, Copyright 2018 The ZCOOL XiaoWei Project Authors, SIL Open Font License 1.1. Original source: https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei (downloaded 2026-10-07). See OFL.txt for the complete license.

`display.woff2` is the source asset for this work. It contains only the title, completion lettering, and Latin wordmark used here; the internal subset family is renamed WindPlay Display. Recreate from upstream ZCOOLXiaoWei-Regular.ttf with fontTools subset and WOFF2 flavor if those words change. CSS uses a local font URL during source inspection. The build embeds the font into the standalone HTML for offline use. The full license is also included in the source CSS and built artifact.
